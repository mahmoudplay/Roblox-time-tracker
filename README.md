# Roblox Time Tracker

**Roblox Time Tracker** is a comprehensive system that combines a **Roblox game (place)**, a **custom API**, and a **Discord bot** to track players’ time spent in your Roblox maps.  

The core idea is simple: when a player enters one of your chosen Roblox maps, the system tracks the time they spend there. Based on the time spent, they accumulate points, which can later be converted into Robux through your Roblox group.  

This project provides an interactive way to **engage your players**, reward their participation, and seamlessly integrate **Roblox gameplay with Discord** for real-time tracking and updates.
